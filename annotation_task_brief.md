# Ransomware Video Annotation Task

**What you'll do:** Review ~180 short cybersecurity YouTube video transcripts and judge, for each one: does it discuss a real ransomware incident, and if so, which ransomware group, which attack stage (MITRE ATT&CK tactic), and which platform (Windows/Linux/ESXi) is discussed. This is for a research dataset on ransomware-related security content.

**Who this is for:** Someone with basic cybersecurity/DFIR familiarity — you should recognize terms like "lateral movement," "initial access," "double extortion" without having to look each one up. Security students, junior analysts, or DFIR-adjacent freelancers are a good fit. Deep expertise isn't required.

**Tool:** A self-contained web tool (link provided separately) — no install needed. One video at a time: read the transcript (or watch the linked YouTube video if you prefer), fill in a short form (Relevant Yes/No/Uncertain, Family, Dominant Tactic, Platform, optional notes), click Save & Next. Your progress autosaves in your browser as you go. The tool has a built-in "Guide" button explaining exactly how to make each call, including what to do when you're unsure (use "Uncertain" rather than guessing).

**Time estimate:** Roughly 6-12 hours total, at your own pace across multiple sessions if needed — progress is saved automatically.

**Deliverable:** When you're done (or need to pause for a while), click "Export progress" in the tool. This downloads a JSON file. Send that file back.

**Important — work independently:** A second person is doing this same task separately. Please don't discuss your answers with them or compare notes before both of you finish — the point is to see where two independent people agree and disagree, which only works if neither of you sees the other's answers first.
